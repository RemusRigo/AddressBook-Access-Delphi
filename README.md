# AddressBook-Access
AddressBook-Access: an address book that uses a Microsoft Access database



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Contacts stored in `Contacts.mdb` (Microsoft Access database, Jet OLE DB)
* Contact list: ID, first name, last name, birth date; click a column to sort
* Add and edit contacts: first name, last name, birth name, birth date
* Alarm: a monthly calendar that shows the contacts' birthdays
